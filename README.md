Rock Paper Scissors 

A browser-based Rock Paper Scissors game created with HTML, CSS, and JavaScript. The project brings the classic game into a simple and interactive web experience where the player competes against a randomly generated computer move.

Each round instantly displays both moves and updates the score based on the outcome. The interface is designed to keep the gameplay clear, smooth, and easy to understand.

Building this project gave me practical experience with JavaScript fundamentals such as handling user interactions, generating random choices, applying conditional game logic, and updating webpage elements dynamically.

Features

- Interactive player vs computer gameplay
- Random computer move generation
- Live score updates after every round
- Instant win, lose, and draw messages
- Displays both player and computer choices
- Responsive and clean interface

Built With

- HTML
- CSS
- JavaScript

Purpose

This project was built as part of my frontend development practice to improve my understanding of JavaScript and interactive web interfaces.
